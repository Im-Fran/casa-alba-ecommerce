# Casa Alba E-Commerce
This is a simple e-commerce website for [Productos Casa Alba](https://instagram.com/productoscasaalba).

## Technologies
- [Laravel v11.x](https://laravel.com)
- [Tailwind CSS v3.x](https://tailwindcss.com)
- [Alpine.js v3.x](https://alpinejs.dev)
- [Livewire v3.x](https://livewire.laravel.com)
- [Lunar v1.x](https://lunarphp.io)

## Packages
If you want to check out the packages used please check `package.json`.

## Installation
You can check the `scripts/init` script to check out the initial setup.
